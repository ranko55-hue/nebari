# Nebari

> אפליקציה שמונעת ממגדלי בונסאי להרוג את העצים שלהם — ומתעדת את הסיפור של כל עץ לאורך שנים.

*Nebari* (根張り) — בסיס הגזע והשורשים החשופים. הדבר הראשון שמסתכלים עליו כשבוחנים בונסאי.

## הרצה

מיגרציות מודבקות לפי הסדר ב-Supabase SQL Editor. עבודה בענן בלבד — GitHub web editor, אין קבצים מקומיים.

## כללי ברזל

1. פרטיות מיקום — אזור אקלים גס בלבד, לעולם לא מיקום מדויק
2. שיתוף הוא opt-in פר עץ
3. התוכן הוא של המשתמשים — אנחנו בונים מנועים
4. מובייל-first, כפתורים גדולים
5. `en.js` היא ברירת המחדל
6. 300 שורות לקובץ
